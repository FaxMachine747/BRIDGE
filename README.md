# Bridge

A website that helps non-autistic people communicate more effectively and respectfully
with autistic classmates, coworkers, friends and family through short, scenario-based
guides instead of long clinical articles.

🔗 Live site: https://bridgeguide.xubi.org

## Features
- 6 real-life scenario guides (school, work, home, public, online, first meeting)
- A myth-busting page with cited facts
- An interactive 5-question self-check quiz with instant feedback
- A "mark as read" progress tracker (saved locally, no account needed)
- A text-size toggle and other accessibility features

## Built with
Plain HTML, CSS and vanilla JavaScript — no frameworks, no backend, no build step.
Hosted for free on GitHub Pages.

## Context
Built as part of an MYP Design project (Criteria A–D). Content is based on cited
research on the "double empathy problem" (Milton, 2012; Crompton et al., 2020) —
see the About & Sources page on the live site for full references.
